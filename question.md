# Đã triển khai backend api với .net 8 và sql server làm database. Hiện tại đã triển khai authen với oauth 2 - openidconenct với openiddict.

# Tôi muốn thực hành với bài toán đáp ứng 1 triệu user đồng thời thao tác với ứng dụng.

# Hạ tầng và triển khai

 - OS - Ubuntu Server
 - Deploy on docker container
 - RAM 16 GB
 - Core 2
 - Disk 80GB

  `Tôi đang triển khai backend web api và sql server trên cùng 1 server này.`

  Cho tôi hỏi với thông tin server này thì có thể phục vụ đồng thời bao nhiều user concurrent user

  Tôi có nên tạo thêm nhiều table nữa như product, category, order để có kịch bản nhiều người thao tác để xem hệ thống chịu tải như nào không

  Tôi muốn giả lập hàng triệu người cùng login xong lấy token đó để thao tác hệ thống đồng thời thì sử dụng gì hướng dẫn tôi làm được điều này.
